Para jogar pela internet, mantenha bx-rp-stream-v15.elf (v13 disponível para retorno) ativo no PS4. A v14 atualiza este site; não exige outro ELF. Use o PS4 salvo em Conectar e jogar.

Carregando cliente Remote Play…

Versão experimental. O payload deve estar ativo no PS4. Conexão HTTPS não comprova que o jogo está funcionando.

1. Autorizar este celular

O modo direto exige a v11 e a mesma rede do PS4. Se o navegador pedir acesso à rede local, permita para conectar ao seu console.

Verificando registro salvo neste navegador…

Salva a chave do jogador e o registro somente neste navegador. Em aparelho compartilhado, desconecte e use Esquecer neste aparelho ao terminar. PIN e Account-ID não são salvos.

2. Registrar o PS4

Registre somente na primeira configuração. Se o PS4 já está salvo neste navegador, use Conectar e jogar; não precisa buscar outro PIN ao trocar de rede ou reiniciar o payload. Para o primeiro registro, use Configurações → Uso remoto → Adicionar dispositivo no PS4. O código do vínculo BX é diferente.

Diagnóstico de registro disponível nesta versão.

O arquivo de registro contém chaves privadas. Guarde-o no seu aparelho.

3. Jogar

A sessão é mantida ao trocar de tela; o navegador pode suspendê-la em segundo plano.

Conecte o controle ao aparelho por Bluetooth ou USB e pressione um botão.

Nenhum quadro decodificado e nenhum áudio recebido.
